# Code of conduct

Our code is the eleven lines of [*In software as in life you need Grace*](./readme.md#in-software-as-in-life-you-need-grace) on Start Here. We hold ourselves to them and ask the same of everyone who takes part. They are stated once, there, and not repeated here.

## Where it applies

In every place the project talks: issues, pull requests, discussions, reviews, and anything else posted for the project.

## How to report

Use GitHub's "Report content", then "Report to repository admins", on the comment or issue. The report reaches the maintainer privately.

## What the maintainer does

The maintainer reads every report and answers the person who made it. When someone has caused harm, the maintainer asks them to make it right. One who will not is removed from the project's spaces. Line 11, *Forgive*, lets back in one who does.

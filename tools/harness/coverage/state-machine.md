## Step 3 — bound saturation

The Alloy model: checks run `for 7` (up to seven entries). The facts make the history a path, so a longer path repeats a link already seen; `ShowReachTerminal` fits inside seven. A rerun `for 9` is owed; not run in this pass.

The TLA+ model:

- At two admitted fires (the shipped bound): 21,734 distinct states, every check holds.
- At three admitted fires: 87,014 distinct states (3 min 39 s in TLC), every check holds. The count grows with the histories a third call adds; the verdicts do not → **saturated** ☑ in verdict. Two fires hold every break the twins make: a repeat of one action, a later entry with an earlier firing instant, a replay that must chain two entries, a walk into a terminal state and a try to leave it. The shipped bound stays at two to keep each run near 15 s.

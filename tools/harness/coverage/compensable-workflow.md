## Step 2 — coverage matrix

The model has one run of two steps, each with a compensating action unless the definition declares none for it (since 2026-11-22), beside another run whose events share the one Event Log instance. The run is the projection the replay derives (the phase, each step's place, the unresolved attempt markers as effect keys, the halt's phase and named steps); beside it the world the page does not own (how many times each effect really landed at its target, and the effect keys a target has forgotten). An invocation is four steps (it takes the critical section, re-enters and marks, runs the effect and learns a verdict, records), so the window between the effect and its record is open; the lease may expire at any point, leaving the expired invocation holding a reply it must discard; a cancel is one step that takes and releases the section. The target answers one of four verdicts at every effect, the pivot is absent or the second step, the compensation failure policy is halt-and-surface or continue, a key lapses only while the run rests halted, and a target's reply to the forward step may exceed the input envelope. The model keeps no history: a property of the state is an invariant over the state, and a property of a step is a name the step adds to `viol` when it breaks the rule.
